# Projet-de-classification

![Projet de Classification](./Projet%20de%20classification/projet-classification.png)

Ce projet analyse des villes européennes à partir de leurs températures mensuelles moyennes en utilisant des méthodes de classification non supervisée sous R. Les approches K-means, CAH et HCPC mettent en évidence trois groupes climatiques distincts : villes froides, tempérées et chaudes, avec des résultats cohérents et robustes.
